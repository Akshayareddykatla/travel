# Travel Together 🌍✈️

Travel Together is a travel buddy platform that connects people with similar travel destinations and interests. The application helps users find compatible travel companions, plan trips together, and share travel experiences safely and conveniently.

---

## 🚀 Features

- 🔐 User Authentication (Login & Signup)
- 👥 Find Travel Buddies
- 🌍 Destination-based Matching
- 💬 Real-time Chat System
- 📅 Trip Planning & Scheduling
- 📍 Location & Route Sharing
- 💰 Expense Sharing
- ⭐ User Ratings & Reviews
- 📱 Responsive Design

---

## ⚙️ Installation

### 1. Clone Repository

```bash
git clone https://github.com/your-username/Travel-Together.git
2. Navigate to Project Folder
cd Travel-Together
3. Install Dependencies
pip install -r requirements.txt
4. Run Application
python app.py
5. Open Browser
http://localhost:5000
🔑 Environment Variables

Create a .env file and add:

MAPS_API_KEY=your_google_maps_api
DATABASE_URL=your_database_url
SECRET_KEY=your_secret_key
